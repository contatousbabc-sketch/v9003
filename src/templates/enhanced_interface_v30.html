Perguntas Frequentes

Como funciona a rotação de APIs?

O sistema utiliza 48+ APIs diferentes e rotaciona automaticamente quando uma falha ou atinge o limite, garantindo coleta contínua de dados.

Posso usar modelos locais?

Sim! O sistema suporta modelos Ollama locais como Llama 3.3, Qwen 3 Coder e outros. Configure na aba "Modelos IA".

Os dados são reais?

100% REAIS! Não utilizamos simulações, placeholders ou dados fictícios. Toda informação é coletada em tempo real de fontes verificadas.

Quanto tempo leva uma análise?

Depende da profundidade: Padrão (5-10 min), Profunda (15-30 min), Ultra (30-60 min). O progresso é mostrado em tempo real.
